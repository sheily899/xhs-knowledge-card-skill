Skill 是什么？

今年 AI 圈一直很火的一个词，就是 Skill。

大家都在说 Skill，但它到底是什么？

今天用最直白、最不绕弯子的方式讲清楚。

先记住这一句

Skill 是一套可以被 Agent 调用的可复用能力包。

它会告诉 Agent：什么情况下应该使用这套能力，按照什么步骤执行，调用什么工具，最后完成什么任务、交付什么结果。

遇到合适的任务，Agent 再读取说明，按步骤执行，并交付结果。
