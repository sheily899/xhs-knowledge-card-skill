# Skill 第 02 页：可编辑 HTML 原型

整套 Skill 的功能、使用流程和边界见项目根目录的 [README.md](../../README.md)。

这是基于第 03 页编辑 Skill 制作的第 02 页实验版，用来观察“定义—解释—工作方式—四步关系”是否适合新手阅读。

## 文件

- `index.html`：可编辑 3:4 HTML 画布，支持文字直接编辑、模块新增/删除/上下移动、IP 替换与拖拽、SVG/PNG 导出。
- `content.json`：第 02 页原始文案。
- `layout.json`：模块顺序、颜色、画布和编辑规则。
- `assets/ip-confused-tangle.png`：当前可用的 IP 素材。第 02 页暂沿用已有素材，后续可通过“替换 IP 图片”换成更符合“想到并解释”情境的图片。

## 预览

在项目目录启动静态服务器：

```powershell
python -m http.server 8765
```

打开 `http://127.0.0.1:8765/outputs/skill-page02-prototype/index.html`。

## 本页重点

- 核心定义只保留一个青色强调块，作为全页第一视觉重点。
- 引言、解释和工作方式保持正文阅读节奏，不把每句话都做成色块。
- 四步关系用轻量横向模块收尾，避免重复使用第 03 页的三行问题列表。
- 文字仍然不自动删改；内容变长时先提示溢出，再由用户调整模块或拆页。
