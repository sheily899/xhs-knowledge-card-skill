# Skill 第 03 页：可编辑 HTML 原型

整套 Skill 的功能、使用流程和边界见项目根目录的 [README.md](../../README.md)。

这是一次“方案可行性”验证，只包含第 03 页，不代表最终五页模板已经定稿。

## 文件

- `index.html`：可编辑 HTML 画布。点击画面中的文字即可编辑；右侧按钮可选择模块形式，新增纯文字、重点色块、列表或四宫格模块，调整模块顺序，删除用户新增的模块，替换 IP 图片，拖拽图片调整左右和上下位置，调整图片大小，恢复图片位置，恢复原文，检查溢出，导出 SVG/PNG。
- `content.json`：本页原始文案，作为内容单一来源。
- `layout.json`：画布尺寸、颜色、字号、模块和“不自动删改文案”的排版约束。
- `assets/ip-confused-tangle.png`：本页使用的 IP 素材。
- `output/skill-page-03.png`：当前 PNG 预览。
- `output/skill-page-03.svg`：独立 SVG 交换文件，文字以原生 `<text>` 节点保存，便于继续测试导入 Figma 的可编辑性。

## 使用

在本目录启动本地静态服务器：

```powershell
python -m http.server 8765
```

然后打开 `http://127.0.0.1:8765/index.html`。

## 当前结论

- HTML 作为主编辑画布是可行的：文字可直接修改，内容模块彼此独立，检查器能提示缺失文字和版式溢出。
- 模块采用正常文档流排列：在场景模块后新增文字时，后面的“问题”和“收束”模块会自动下移；模块可上下移动，固定模块不会被误删。
- 新增模块有四种形式：纯文字（无格式）、重点色块、列表、四宫格。只有用户新增的模块可以删除，固定内容区保持保护。
- 图片可以通过本地文件选择器替换；可以直接拖拽图片调整左右和上下位置，也可以用滑杆精细调整大小和上下位置，并一键恢复初始位置。
- PNG 导出是可行的；SVG 也可以导出，但最终是否在 Figma 中保留为可编辑文字，还需要用实际 Figma 导入结果继续验证。
- 这版不会因为空间不足而静默删除或改写用户文案；如果内容变长，应进入“调整版式 / 确认是否删减”的下一步，而不是自动缩到不可读。
