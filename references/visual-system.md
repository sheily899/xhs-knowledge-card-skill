# 视觉系统与排版基线

本文件说明当前小红书知识卡片的视觉基线。需要新建页面或调整风格时读取；如果用户提供了新的明确视觉规范，以用户规范为准。

## 画布与颜色

| 项目 | 默认值 |
| --- | --- |
| 尺寸 | 1080 × 1440 |
| 比例 | 3:4 竖版 |
| 背景 | 纯白 |
| 主文字 | 深色，用于正文和主要标题 |
| 强调色 | 从用户 IP 或已确认样式提取的青色 |
| 辅助底色 | 很浅的青色，仅用于必要的信息区分 |

强调色用于 Skill、核心定义、编号、线条或少量关键词，不要让页面上所有文字都变成重点。

## 文字层级

默认只保留三层：

1. 标题：最大字号，负责页面主问题或结论；
2. 正文：稳定字号和行距，负责完整表达；
3. 强调：加粗、青色或浅色块，用于少量关键内容。

避免为每一小段文字设置不同字号。字号不足以承载内容时，优先调整模块结构，而不是无限缩小正文。

## 留白与安全区

- 标题、正文和 IP 不贴近画布边缘；
- 模块之间用间距或细线区分，不依赖厚重卡片；
- IP 周围保留呼吸空间，不用人物填满空白；
- 先确保手机缩略图能读清标题和核心信息，再调整细节；
- 留白是阅读层级的一部分，不是需要被消除的空区域。

## 字体稳定性

当前原型使用系统字体回退栈。不同电脑没有安装相同字体时，字宽、换行和模块高度可能变化。正式导出前，应在实际使用环境中检查：

- 中文断行；
- 标题宽度；
- 正文行数；
- 页面底部是否溢出。
