# 模块选择与编辑规则

本文件说明内容块如何转换为可编辑模块，以及模块之间如何保持可调整。需要设计或修改页面模块时读取。

## 当前支持的模块

| 模块 | 适合内容 | 使用限制 |
| --- | --- | --- |
| 纯文字 | 过渡、补充说明、完整叙述 | 不额外添加色块，保证连续阅读 |
| 重点色块 | 定义、结论、需要记住的一句话 | 一块只突出一个中心，不把整段都做成重点 |
| 列表 | 有顺序或并列关系的内容 | 每项保留标题和必要解释 |
| 四宫格 | 四个平行价值、特点或步骤 | 四项需要具有相对平行的语义层级 |

关系链、流程图和更复杂的结构可以作为页面专门版式实现，但当前不是通用“新增模块”按钮。不要在 Skill 已有能力之外做出虚假承诺。

## 模块判断

- 只有一句核心定义时，优先考虑重点色块。
- 文字承担解释作用时，优先保持纯文字。
- 多个项目可以快速扫读时，考虑列表。
- 四项平行内容需要并列比较时，考虑四宫格。
- 只有在原文明确表达“先后、因果或输入输出”时，才建议关系链。

## 固定模块与自定义模块

| 类型 | 默认行为 |
| --- | --- |
| 固定模块 | 页面原始结构，默认保护，避免误删已确认内容 |
| 自定义模块 | 用户后来新增的补充内容，可以删除、上移、下移 |

页面采用正常文档流。模块内容变长时，后续模块自动下移；删除模块后，后续模块自然上移。不要把每个模块写死在画布坐标中，否则新增内容会造成遮挡。

## 模块操作

编辑界面应优先提供少量高频操作：

- 新增；
- 删除；
- 上移；
- 下移；
- 选择模块形式。

按钮之间保留明确间距，避免误触。固定模块若需要删除，应先把它视为内容结构变更并明确记录。

## IP 模块

IP 是独立的视觉素材层，不属于普通文本模块。它可以替换、拖拽、缩放和恢复位置，但不应遮挡标题、正文或模块内容。缺少合适姿势时，优先调整版式，不生成新的角色。
