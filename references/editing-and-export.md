# 编辑、检查与导出

本文件说明如何使用 HTML 画布，以及不同导出格式的实际边界。需要编辑原型、处理图片或导出文件时读取。

## 浏览器编辑

打开生成的卡片文件后，直接在画布中操作：

- 点击文字并修改；
- 新增纯文字、重点色块、列表或四宫格；
- 删除用户新增模块；
- 上移或下移模块；
- 替换 IP 图片；
- 拖拽图片调整左右和上下位置；
- 调整图片大小或恢复初始位置；
- 运行检查并导出。

用户不需要先理解 HTML、CSS 或 JSON。只有本地资源加载或浏览器导出受限时，才使用本地静态服务器作为备用打开方式。

## 数据与保存

- HTML 是主要编辑源。
- `content.json` 保存页面原始文案，`layout.json` 保存页面结构和样式规则；它们是项目数据，不是普通用户必须编辑的入口。
- 当前版本的浏览器临时编辑不会自动回写这两个 JSON 文件。
- 需要长期保留修改时，保存修改后的 HTML，并同步更新对应源文件。

## 导出格式

| 格式 | 用途 | 边界 |
| --- | --- | --- |
| PNG | 小红书发布和视觉预览 | 导出后不能继续编辑文字 |
| SVG | 交换、归档或尝试导入 Figma | CSS、图片和 `foreignObject` 可能在其他工具中变化 |
| Figma | 后续人工微调 | 不保证导入后全部文字变成原生可编辑图层 |

不要把“SVG 文件导出成功”理解为“Figma 一定完整可编辑”。需要在目标 Figma 环境中实际导入、检查文字和图片图层。

## 导出前检查

- 文案没有漏字或被静默改写；
- 中文断行自然；
- 标题和核心内容在缩略图中仍然清晰；
- 模块没有空内容或互相遮挡；
- IP 没有被裁切；
- 页面没有溢出画布；
- PNG 已经实际打开查看；
- SVG 或 Figma 导入结果已经单独验证。
